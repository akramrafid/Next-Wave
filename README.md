# Next-Wave

Next-Wave is a modern, bold, and dynamic web application featuring sleek glassmorphism UI, advanced interactive components, and premium brand aesthetics. Built with React and Tailwind CSS.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/akramrafid/Next-Wave.git
   ```
2. Navigate into the project directory:
   ```bash
   cd "Nextwave v1"
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Features
- **Responsive Layout:** Perfectly scales from mobile to ultra-wide displays.
- **Glassmorphism UI:** Advanced CSS filters and GPU acceleration for premium styling.
- **Interactive Dashboards:** Orbital animated layouts and interactive cards.
- **AI Chatbot Integration:** Built-in floating AI assistant component.
